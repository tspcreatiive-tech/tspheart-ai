# TSP Heart AI Website

Static website built with HTML, CSS and JavaScript.

## Free publishing — GitHub Pages
1. Create a free GitHub account.
2. Create a new public repository, e.g. `tspheart-ai`.
3. Upload `index.html`, `style.css`, and `script.js`.
4. Go to **Settings → Pages**.
5. Select **Deploy from a branch → main → /root** and save.
6. GitHub will provide a free `github.io` URL.

## Custom domain
If you own `tspheart.ai`, add it in GitHub Pages under **Custom domain**, then create the DNS records requested by GitHub at your domain provider.
